# MIT Quantum Information Science

## Overview

This section provides a structured learning pathway for **Quantum Information Science (QIS)** based on selected MIT Open Learning courses.

The pathway currently covers **six MIT QIS courses**, spanning the MIT 8.370x and 8.371x course sequences.

The detailed working course-level extraction summaries are maintained in the `mit_courses` working repository. This FAEP Academy section provides the learning-path navigation and links to those extracted materials.

> **Purpose:** provide a structured QIS learning pathway within FAEP Academy while keeping the detailed course extraction work in the dedicated `mit_courses` repository.

## Recommended Learning Process

Learners can use this pathway as follows:

1. Start with **MIT 8.370.1x**.
2. Continue through **8.370.2x** and **8.370.3x**.
3. Progress to **8.371.1x**, **8.371.2x**, and **8.371.3x**.
4. Use the corresponding working extraction summary when reviewing each course.
5. Return to the original MIT course material whenever deeper clarification is required.
6. Identify concepts relevant to QAI, FAEP, and systems engineering.
7. Develop independent examples and experiments.
8. Keep original QAI/FAEP implementations separate from the external course material.
