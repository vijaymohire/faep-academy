# FAEP Academy Schools

> School-based navigation that organizes educational resources according to engineering methodologies, scientific paradigms, architectural approaches, and ways of thinking.

---

# Overview

The **schools** directory provides a methodology-oriented view of the FAEP Academy.

Rather than organizing educational resources by technology, profession, industry, or engineering competency, school-based navigation groups notebooks, tutorials, laboratories, projects, and case studies according to different engineering philosophies, problem-solving approaches, and schools of thought.

Each school references reusable educational assets without duplicating content.

---

# Purpose

School navigation helps answer questions such as:

- I want to learn Systems Thinking.
- Where can I study Model-Based Systems Engineering?
- Which notebooks use Design Thinking?
- How is Scientific Computing applied?
- Which engineering methodology best supports my learning objectives?

Schools represent different perspectives for understanding, designing, and solving engineering problems.

# FAEP Perspective

Schools provide a methodology-based navigation layer across the FAEP Academy.

Engineering is not only about technologies but also about approaches to thinking, designing, modeling, validating, and solving complex problems. School-based navigation encourages learners to explore multiple engineering perspectives while reusing the same educational assets across different methodologies, promoting multidisciplinary understanding and lifelong learning.

## FAEP Education

Building methodology-oriented learning experiences that connect reusable engineering knowledge assets with systems thinking, scientific inquiry, architectural design, computational methods, and multidisciplinary engineering practices.
