# Python Programming Exercises

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains the practical exercises for the Python Programming course.

The exercises reinforce the concepts introduced in each notebook and encourage learners to apply their knowledge through experimentation, problem solving, and engineering practice.

Exercises are designed to progress from simple programming tasks to more challenging engineering problems.

---

# Learning Philosophy

Programming is best learned by writing code.

Each exercise encourages learners to:

- Apply newly learned concepts
- Experiment with different solutions
- Develop problem-solving skills
- Build confidence through practice
- Prepare for engineering projects

Learners are encouraged to complete every exercise before reviewing the companion solution notebook.

---

# Exercise Categories

The course uses progressive difficulty levels.

| Level | Description |
|--------|-------------|
| ⭐ Practice | Reinforce concepts introduced in the notebook |
| ⭐⭐ Challenge | Apply concepts to slightly larger problems |
| ⭐⭐⭐ Engineering | Solve practical engineering tasks |
| ⭐⭐⭐⭐ Exploration | Extend the notebook through independent experimentation |

# Exercise Types

Examples include:

- Complete missing code
- Predict program output
- Debug existing programs
- Modify notebook examples
- Create reusable functions
- Read and process data
- Visualize results
- Optimize simple programs
- Explain observations

---

# Engineering Approach

Learners are encouraged to:

- Write clean and readable code
- Test programs with different inputs
- Document observations
- Compare multiple solutions
- Consider performance and maintainability
- Think beyond obtaining the correct answer

---

# Good Practices

When completing exercises:

- Attempt every exercise independently.
- Avoid viewing solutions too early.
- Experiment with alternative approaches.
- Record lessons learned.
- Improve your own code after reviewing the reference solution.
