# Overview

This exercise introduces Python operators used to perform calculations, compare values, evaluate logical conditions, and manipulate variables.

Operators are fundamental building blocks of programming and are used throughout software engineering, data science, artificial intelligence, and scientific computing.

- Use arithmetic operators
- Apply comparison operators
- Evaluate logical expressions
- Update variables using assignment operators

# Exercise 1 — Arithmetic Operators

Create two variables:

```text
a = 20
b = 6
```

Calculate:

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Exponentiation

Display each result clearly.

---

# Exercise 2 — Comparison Operators

Using the same variables, evaluate:

- ==
- !=
- >
- <
- >=
- <=

Display each Boolean result.

---

# Exercise 3 — Logical Operators

Create two Boolean variables.

Use:

- and
- or
- not

Display the result of each logical expression.

---

# Exercise 4 — Assignment Operators

Create:

```text
counter = 10
```

Update the variable using:

- +=
- -=
- *=
- /=

Print the value after each operation.

---

# Exercise 5 — Membership Operators

Create a list of programming languages.

Determine whether:

```text
"Python"
```

and

```text
"Java"
```

exist in the list using:

- in
- not in

Display the results.

---

# Exercise 6 — Operator Precedence

Evaluate the following expressions and explain why the results differ.

```python
5 + 3 * 2

(5 + 3) * 2

20 / 5 + 2

20 / (5 + 2)
```
