# Overview

Conditional statements allow programs to make decisions based on different conditions.

This exercise introduces the use of **if**, **elif**, and **else** statements to control the flow of a program and solve practical engineering problems.

---

# Learning Objectives

After completing this exercise you should be able to:

- Use `if` statements
- Use `if-else` statements
- Use `if-elif-else` statements
- Evaluate Boolean expressions
- Apply logical operators in conditions
- Design simple decision-making programs

# Exercise 1 — Positive or Negative

Create a variable called:

```text
number
```

Write a program that determines whether the number is:

- Positive
- Negative
- Zero

Display an appropriate message.

---

# Exercise 2 — Even or Odd

Create an integer variable.

Determine whether the number is:

- Even
- Odd

Display the result.

---

# Exercise 3 — Age Classification

Create a variable:

```text
age
```

Display one of the following:

- Child
- Teenager
- Adult
- Senior

Choose appropriate age ranges.

---

# Exercise 4 — Student Grade

Create a variable:

```text
score
```

Display a grade using the following example ranges:

| Score | Grade |
|--------|-------|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

---

# Exercise 5 — Login Validation

Create variables representing:

- Username
- Password

Compare them with predefined values.

Display:

- Access Granted
- Access Denied

---

# Exercise 6 — Weather Recommendation

Create a variable:

```text
temperature
```

Display a recommendation such as:

- Wear a jacket
- Comfortable weather
- Stay hydrated

based on the temperature.

---

# Challenge Exercise ⭐⭐

Develop a simple ATM decision program.

Requirements:

- Current balance
- Withdrawal amount

Determine whether:

- Withdrawal is successful
- Insufficient balance
- Invalid amount

Display an appropriate message.

---

# Engineering Extension ⭐⭐⭐

Create a system health monitor.

Given a CPU utilisation value:

| CPU Usage | Status |
|-----------|--------|
| 0–50% | Normal |
| 51–80% | Busy |
| 81–95% | High Load |
| Above 95% | Critical |

Display the corresponding system status and recommend an action.
