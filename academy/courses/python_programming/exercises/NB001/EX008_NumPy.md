# Overview

NumPy is one of Python's most widely used scientific computing libraries.

It provides efficient multidimensional arrays and mathematical operations that form the foundation for data science, engineering, artificial intelligence, machine learning, and scientific research.

This exercise introduces the fundamental concepts required for future notebooks.
