# Overview

Lists are one of Python's most commonly used data structures. They allow programs to store, organize, and process collections of related values.

This exercise introduces creating lists, accessing elements, modifying data, iterating through collections, and performing basic list operations.

---

# Learning Objectives

After completing this exercise you should be able to:

- Create Python lists
- Access list elements
- Modify list contents
- Add and remove elements
- Iterate through lists
- Apply common list methods
