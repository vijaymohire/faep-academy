# Overview

Matplotlib is one of Python's most widely used libraries for creating charts and visualizing data.

Visualization helps engineers, scientists, and analysts understand patterns, trends, and relationships within data.

This exercise introduces the basic plotting capabilities required for future notebooks and projects.

---

# Learning Objectives

After completing this exercise you should be able to:

- Import Matplotlib
- Create simple plots
- Add chart titles
- Label chart axes
- Display multiple data points
- Visualize engineering datasets
