# Overview

This exercise introduces Python variables and demonstrates how information can be stored, updated, and displayed within a program.

Variables are one of the fundamental building blocks of programming and are used throughout the remainder of this course.

---

# Learning Objectives

After completing this exercise you should be able to:

- Create variables
- Assign values to variables
- Use meaningful variable names
- Display variable values
- Modify variable contents
- Understand basic data storage in Python

---

# Prerequisites

Complete:

- Notebook NB001
- Notebook examples on variables

---

# Instructions

Complete each task independently before reviewing the companion solution notebook.

Experiment with different values and observe the program output.

---

# Exercise 1 — Create Variables

Create variables for:

- Your name
- Your age
- Your favourite programming language

Print each variable.

---

# Exercise 2 — Engineering Information

Create variables for:

- Company name
- Project name
- Version number

Display the information in a readable format.

---

# Exercise 3 — Numeric Variables

Create variables representing:

- Length
- Width
- Height

Calculate:

- Area
- Volume (assume appropriate dimensions)

Print the results.

---

# Exercise 4 — Updating Variables

Create a variable called:

```text
counter
```

Set it to:

```text
0
```

Increase the value five times.

Print the result after each update.

---

# Exercise 5 — Personal Profile

Create variables for:

- Name
- Country
- Profession
- Years of Experience

Display the information using formatted output.

---

# Challenge Exercise ⭐⭐

Create a simple student record using variables.

Include:

- Student ID
- Name
- Course
- Marks

Calculate whether the student has passed based on a passing mark of 50.

Display an appropriate message.

---

After completing the exercise, consider:

1. Why are variables useful?
2. What makes a variable name meaningful?
3. When should variable values be updated?
4. How do variables improve program readability?
