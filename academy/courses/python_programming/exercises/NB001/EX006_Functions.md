# Overview

Functions allow programs to organize code into reusable, modular components.

This exercise introduces function definition, parameters, return values, and function reuse through practical programming examples.

Functions improve readability, maintainability, testing, and software engineering quality.

---

# Learning Objectives

After completing this exercise you should be able to:

- Define functions
- Call functions
- Pass parameters
- Return values
- Reuse functions
- Develop modular programs

---

# Exercise 1 — Greeting Function

Create a function called:

```text
greet()
```

The function should display a welcome message.

Call the function three times.

---

# Exercise 2 — Function with Parameters

Create a function:

```text
display_name(name)
```

Pass different names to the function.

Display a personalised greeting.

---

# Exercise 3 — Addition Function

Create a function:

```text
add_numbers(a, b)
```

Return the sum of two numbers.

Display the returned value.

---

# Exercise 4 — Area Calculator

Create a function:

```text
calculate_area(length, width)
```

Return the rectangle area.

Test the function using several values.

---

# Exercise 5 — Even Number Checker

Create a function:

```text
is_even(number)
```

Return:

- True
- False

Test using several numbers.

---

# Exercise 6 — List Average

Create a function:

```text
calculate_average(numbers)
```

Accept a list of numbers.

Return the average value.

Use the sample numbers from:

```text
DATA001_Sample_Numbers.csv
```
