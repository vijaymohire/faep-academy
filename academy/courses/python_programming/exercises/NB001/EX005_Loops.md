# Overview

Loops allow programs to repeat a sequence of instructions efficiently without duplicating code.

This exercise introduces Python's **for** and **while** loops and demonstrates how iteration is used to automate repetitive tasks in software engineering and scientific computing.

---

# Learning Objectives

After completing this exercise you should be able to:

- Use `for` loops
- Use `while` loops
- Iterate over sequences
- Control loop execution
- Apply loops to practical programming problems

Complete each exercise independently before reviewing the companion solution notebook.

---

# Exercise 1 — Counting with a For Loop

Write a program that prints the numbers:

```text
1
2
3
...
10
```

using a `for` loop.

---

# Exercise 2 — Even Numbers

Use a `for` loop to display all even numbers between:

```text
1 and 20
```

---

# Exercise 3 — Multiplication Table

Create a multiplication table for a number chosen by the user.

Display the results from:

```text
1 × number

to

10 × number
```

---

# Exercise 4 — Sum of Numbers

Calculate the sum of the numbers from:

```text
1 to 100
```

using a loop.

Display the final result.

---

# Exercise 5 — While Loop Counter

Use a `while` loop to print:

```text
Countdown

10

9

8

...

1
```

Display:

```text
Lift Off!
```

when the countdown finishes.

---

# Exercise 6 — Loop Through a List

Create a list containing several programming languages.

Display each language using a loop.

Example:

- Python
- Java
- C++
- Go
- Rust
