# Overview

This exercise introduces the fundamental data types available in Python.

Understanding data types is essential because every value stored in a program has an associated type that determines how it can be processed and manipulated.

---

# Learning Objectives

After completing this exercise you should be able to:

- Create variables using different data types
- Identify common Python data types
- Use the `type()` function
- Convert between compatible data types
- Understand when different data types should be used

Complete each exercise independently before reviewing the companion solution notebook.

# Exercise 1 — Integer Variables

Create variables representing:

- Number of students
- Number of projects
- Year

Print each value.

Display the data type using:

```python
type(variable_name)
```

---

- Height

Display the corresponding data type.

# Exercise 3 — Strings

- Course
- City

Determine the data type.

---

# Exercise 4 — Boolean Values

Print each value.

# Exercise 5 — Collections

- Tuple

# Exercise 6 — Type Conversion
