# Project Overview

In this guided project, learners will develop a menu-driven Python calculator that demonstrates the programming concepts introduced throughout NB001.

The calculator provides an opportunity to integrate variables, operators, conditional statements, loops, functions, lists, and basic data analysis into a practical software application.

---

# Learning Objectives

After completing this project you should be able to:

- Design a simple software application
- Organize code into reusable functions
- Implement menu-driven programs
- Perform mathematical calculations
- Validate user input
- Apply software engineering best practices

```text

↓

display_menu()

↓

↓

↓

```
