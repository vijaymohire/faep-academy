# Python Programming Projects

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains the practical programming projects for the Python Programming course.

Projects provide learners with the opportunity to integrate concepts learned throughout the notebooks and exercises into complete, working applications.

Unlike individual exercises, projects require learners to plan, design, implement, test, and improve software solutions using good engineering practices.

---

# Learning Philosophy

Projects encourage learners to:

- Apply programming knowledge to practical problems
- Develop structured software solutions
- Improve engineering thinking
- Build confidence through hands-on experience
- Create a portfolio of completed work

Projects are intentionally open-ended to encourage creativity and multiple valid solutions.

---

---

# Engineering Best Practices

Learners are encouraged to:

- Plan before writing code.
- Break problems into smaller components.
- Use reusable functions.
- Follow consistent naming conventions.
- Document code clearly.
- Test with different inputs.
- Improve readability and maintainability.

Projects should demonstrate both programming ability and engineering judgement.
