# Screenshot Library

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains annotated screenshots that introduce learners to the software tools, development environments, and user interfaces used throughout the Python Programming course.

Screenshots provide visual guidance that helps learners become familiar with professional development tools before they begin writing code.

Within the FAEP Academy, screenshots reduce the learning curve by demonstrating real software environments and expected user interactions.

---

# Purpose

The screenshot library helps learners to:

- Recognize software interfaces
- Navigate development tools
- Understand notebook environments
- Follow practical tutorials
- Verify application layouts
- Build confidence using professional software
