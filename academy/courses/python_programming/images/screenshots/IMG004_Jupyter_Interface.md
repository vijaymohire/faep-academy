# Best Practices

When using Jupyter Notebooks:

- Read the instructions before running code.
- Execute cells in sequence.
- Save your work regularly.
- Keep Markdown notes organised.
- Restart the kernel if results appear inconsistent.
- Experiment by modifying example code.
