# Overview

This diagram illustrates how Python programs control the execution of instructions through sequential execution, decision making, and repetition.

Understanding control flow is essential because every Python program follows a logical sequence of execution.

---

# Purpose

The control flow diagram helps learners:

- Understand program execution
- Visualize decision making
- Understand repetition using loops
- Connect programming concepts together
- Improve computational thinking

---

# Control Flow Model

The diagram should illustrate the following workflow:

```text
Program Starts

↓

Input

↓

Processing

↓

Decision (if / else)

↓

True ---------------------- False
 |                            |
 |                            |
 V                            V
Execute Block A         Execute Block B

↓

Loop Required?

↓

Yes ---------------------- No
 |                            |
 |                            |
 V                            |
Repeat Processing             |
 |                            |
 └───────────────←────────────┘

↓

Display Output

↓

Program Ends
```

# Learning Outcomes

After studying this diagram, learners should understand:

- Programs execute one instruction at a time.
- Decisions determine execution paths.
- Loops repeat selected operations.
- Programs eventually terminate after completing all tasks.
