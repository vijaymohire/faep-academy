# Overview

This flowchart illustrates how Python functions are defined, called, executed, and how values are returned to the calling program.

Functions are fundamental building blocks of software engineering because they enable reusable, modular, and maintainable code.

---

# Purpose

The flowchart helps learners:

- Understand function execution
- Visualize parameter passing
- Follow program control
- Understand return values
- Appreciate modular programming

# Function Execution Flow

```text
Program Starts

↓

Function Called

↓

Pass Parameters

↓

Execute Function Body

↓

Perform Processing

↓

Return Result

↓

Continue Program Execution

↓

Program Ends
```

---

# Detailed Function Workflow

A typical function execution sequence is:

```text
Define Function

↓

Call Function

↓

Receive Arguments

↓

Execute Statements

↓

Calculate Result

↓

Return Value

↓

Caller Receives Result

↓

Continue Execution
```
