# Flowchart Library

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains flowcharts that illustrate the logical execution of Python programs and software engineering processes.

Flowcharts complement the notebooks, exercises, and projects by providing visual representations of program logic, function execution, decision making, and engineering workflows.

Within the FAEP Academy, flowcharts are used to help learners understand *how* software executes before writing code.

---

# Purpose

The flowchart library helps learners to:

- Visualize program execution
- Understand software logic
- Improve computational thinking
- Learn structured programming
- Plan solutions before coding
- Develop engineering problem-solving skills
