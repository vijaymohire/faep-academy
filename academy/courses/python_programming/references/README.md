# Overview

This folder contains the reference materials used throughout the Python Programming course.

The references provide additional explanations, official documentation, recommended books, tutorials, articles, videos, and engineering resources that complement the notebooks, exercises, and projects.

Learners are encouraged to use these resources to deepen their understanding and continue learning beyond the course.

---

# Learning Philosophy

Programming is a continuously evolving discipline.

The FAEP Academy encourages learners to:

- Read official documentation
- Compare multiple learning resources
- Explore new programming techniques
- Develop independent research skills
- Continue learning beyond structured coursework

Learning does not end with course completion.
