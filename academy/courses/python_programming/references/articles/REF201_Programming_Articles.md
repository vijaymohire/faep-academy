# Overview

This document provides a curated collection of recommended programming articles that complement the Python Programming course.

Unlike books, articles provide concise explanations, practical examples, industry updates, best practices, and insights into specific programming topics. They are ideal for continuous learning and staying current with evolving technologies.

Within the FAEP Academy, articles are intended to supplement—not replace—the interactive notebooks, exercises, projects, and official documentation.
