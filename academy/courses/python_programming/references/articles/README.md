# Overview

This folder contains curated technical articles that complement the Python Programming course.

Articles provide focused discussions on programming concepts, software engineering practices, emerging technologies, development tools, and practical implementation techniques. They complement the interactive notebooks, programming exercises, guided projects, official documentation, and recommended books.

Within the FAEP Academy, articles are intended to support continuous learning by exposing learners to practical engineering perspectives beyond the core course material.

The article library helps learners to:

- Explore programming topics in greater depth
- Learn industry best practices
- Stay informed about evolving technologies
- Discover practical implementation techniques
- Reinforce concepts introduced in the course
- Develop habits of continuous professional learning
