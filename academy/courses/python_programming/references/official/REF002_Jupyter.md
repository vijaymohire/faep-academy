# Keyboard Shortcuts

Frequently used shortcuts include:

| Shortcut | Action |
|----------|--------|
| Shift + Enter | Run current cell and move to next |
| Ctrl + Enter | Run current cell |
| A | Insert cell above (Command Mode) |
| B | Insert cell below (Command Mode) |
| M | Convert to Markdown |
| Y | Convert to Code |
| DD | Delete selected cell |
| Z | Undo deleted cell |

---

# Best Practices

While working with notebooks:

- Run cells in sequence.
- Restart the kernel when necessary.
- Save notebooks frequently.
- Add descriptive Markdown.
- Keep code organized into small cells.
- Document assumptions and observations.
- Test changes incrementally.
