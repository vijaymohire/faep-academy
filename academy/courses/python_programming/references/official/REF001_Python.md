# Overview

Python is a high-level, interpreted programming language widely used in software engineering, data science, artificial intelligence, scientific computing, automation, and web development.

The official Python documentation is the primary reference for learning the language, understanding its standard library, and following recommended programming practices.

This document provides an overview of the most important official Python resources for learners enrolled in the FAEP Academy.
