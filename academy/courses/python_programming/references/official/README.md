# Overview

This folder contains official technical references that support the Python Programming course.

The references introduce learners to authoritative documentation, industry-standard resources, and official project websites for the technologies used throughout the course.

Rather than replacing the course material, these references complement the notebooks, exercises, projects, and study guides by encouraging learners to consult trusted technical documentation.

---

# Purpose

The official references help learners to:

- Develop independent learning skills
- Navigate official documentation
- Understand technology ecosystems
- Explore advanced features beyond the course
- Follow industry best practices
- Build habits used by professional software engineers
