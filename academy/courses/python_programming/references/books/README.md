# Overview

This folder contains a curated collection of recommended books that support the Python Programming course.

The books have been selected to complement the interactive notebooks, programming exercises, guided projects, and official documentation used throughout the FAEP Academy.

Rather than replacing hands-on learning, these books provide additional explanations, alternative perspectives, deeper technical knowledge, and professional software engineering practices.

# Best Practices

To gain maximum value from technical books:

- Read selectively based on current learning objectives.
- Practice concepts while reading.
- Take notes and summarize key ideas.
- Revisit important chapters as your skills grow.
- Compare different authors' approaches.
- Apply new techniques in guided projects.
