# Reference 101 – Recommended Books

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This document provides a curated collection of recommended books for learners enrolled in the Python Programming course.

The books have been selected to support different stages of learning, from beginner programming through intermediate software engineering and scientific computing.

Rather than reading every book cover to cover, learners are encouraged to use these resources to reinforce concepts introduced throughout the course.

---

# Learning Objectives

These recommended books help learners to:

- Strengthen Python programming skills
- Develop software engineering practices
- Improve computational thinking
- Explore scientific computing
- Build professional programming knowledge
- Continue learning beyond the course

---
