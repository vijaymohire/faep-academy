> **FAEP Academy | Python Programming Foundations**

# Overview

This document provides a curated collection of recommended video resources that support the Python Programming course.

Videos complement the interactive notebooks, exercises, projects, books, and official documentation by providing visual demonstrations, instructor-led explanations, and practical programming examples.

Within the FAEP Academy, videos are intended to reinforce learning rather than replace hands-on practice.

After using these video resources, learners should be able to:

# Best Practices

When learning from videos:

- Watch actively rather than passively.
- Pause and reproduce demonstrations.
- Take notes on important ideas.
- Experiment with the examples.
- Compare demonstrations with official documentation.
- Apply new techniques in guided projects.
