# Python Programming Notebooks

> **FAEP Academy | Python Programming Foundations**

# Overview

This folder contains the interactive Jupyter notebooks used throughout the Python Programming course.

Each notebook builds progressively upon concepts introduced in previous notebooks and combines theory, executable code, experimentation, engineering discussion, and practical exercises.

Learners are encouraged to complete the notebooks sequentially.

---

# Notebook Learning Philosophy

Each notebook follows the FAEP Standard Notebook Framework:

- Overview
- Learning Objectives
- Background Theory
- Mathematics (where applicable)
- Engineering Concepts
- Implementation
- Experiments
- Exercises
- Validation
- Summary
- References

Recommended environments:

- Jupyter Notebook
- JupyterLab
- Visual Studio Code
- Google Colab

Before beginning:

- Install required libraries
- Execute from a clean kernel
- Run notebook cells sequentially
- Complete all exercises before reviewing solutions
