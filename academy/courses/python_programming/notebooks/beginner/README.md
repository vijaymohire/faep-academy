# Overview

This folder contains the beginner-level Jupyter notebooks for the Python Programming course.

The notebooks introduce fundamental Python programming concepts through interactive examples, explanations, and hands-on coding exercises. They are designed for learners with little or no prior programming experience.

Each notebook builds upon the previous one, gradually developing practical programming skills and engineering problem-solving abilities.
