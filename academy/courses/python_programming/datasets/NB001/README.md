# DATA002 – Student Scores

## Purpose

This dataset demonstrates how Python can be used to read, process, analyse, and visualize structured tabular data.

It supports examples involving:

- CSV file processing
- Lists and dictionaries
- Functions
- NumPy arrays
- Pandas DataFrames
- Statistical calculations
- Data visualization

## Dataset Structure

| Column | Description |
|---------|-------------|
| StudentID | Unique student identifier |
| StudentName | Student name |
| Python | Python programming score |
| Mathematics | Mathematics score |
| Science | Science score |

## Sample Learning Activities

Learners can use this dataset to:

- Calculate average scores
- Find highest and lowest marks
- Create summary statistics
- Sort students by score
- Filter students based on performance
- Generate charts and graphs
- Export processed results

## Size

10 records

## Source

FAEP Academy

Synthetic educational dataset created for learning and demonstration purposes.
