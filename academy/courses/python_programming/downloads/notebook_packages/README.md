# Notebook Packages

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains downloadable notebook packages for the Python Programming course.

Notebook packages provide convenient offline access to one or more Jupyter notebooks together with any supporting resources required to complete the associated learning activities.

Packages are particularly useful for learners who prefer offline study, classroom delivery, or maintaining a local archive of course materials.

---

# Learning Philosophy

Interactive notebooks are the primary learning resource within the FAEP Academy.

Notebook packages provide a convenient way to:

- Download complete learning modules
- Study offline
- Share course material in workshops
- Backup learning resources
- Build a personal notebook library
