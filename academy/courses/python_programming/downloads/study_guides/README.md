# Study Guides

> **FAEP Academy | Python Programming Foundations**

---

# Overview

This folder contains study guides that support the Python Programming course.

Study guides help learners consolidate their understanding after completing notebooks, exercises, and projects. They summarize key concepts, highlight important learning outcomes, and provide revision checklists before progressing to the next learning module.

Unlike cheat sheets, study guides focus on concept review, learning progression, and self-assessment rather than syntax alone.

---

# Learning Philosophy

The FAEP Academy encourages continuous learning through structured revision.

Study guides help learners to:

- Reinforce important concepts
- Review notebook content
- Prepare for practical exercises
- Identify knowledge gaps
- Build confidence before advancing to the next topic
