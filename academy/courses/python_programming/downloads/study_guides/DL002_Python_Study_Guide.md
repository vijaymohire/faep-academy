# Key Concepts

## Python

- High-level programming language
- Easy to read
- Widely used in engineering and AI

---

## Variables

Variables store data for later use.

Example:

```python
name = "Alice"
score = 90
```

---

## Data Types

Common data types include:

- Integer
- Float
- String
- Boolean
- List
- Dictionary
- Tuple

---

## Control Flow

Programs make decisions using:

- if
- elif
- else

Programs repeat work using:

- for
- while

---

## Functions

Functions improve:

- Reusability
- Readability
- Maintainability

---

## Scientific Computing

Python supports engineering through libraries such as:

- NumPy
- Pandas
- Matplotlib

These libraries will be explored in greater detail in later notebooks.
