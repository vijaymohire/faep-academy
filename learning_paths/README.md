# FAEP Academy Learning Paths

> Structured navigation guides that connect notebooks, tutorials, laboratories, case studies, and engineering resources into progressive learning journeys.

---

# Overview

The **learning_paths** directory provides curated educational journeys through the FAEP Academy.

Unlike the `notebooks` directory, which stores educational content, learning paths organize that content into recommended sequences based on learning goals, domains, professional roles, industries, and engineering capabilities.

Learning paths reference existing educational assets without duplicating them.

---

# Purpose

Learning paths help answer questions such as:

- Where should I start?
- What should I study next?
- Which notebooks are recommended?
- Which laboratories support this topic?
- Which mathematical concepts should I learn first?
- Which engineering capabilities will I develop?

---

# Navigation Philosophy

FAEP Academy separates **content** from **navigation**.

```
Educational Content

    notebooks/
    tutorials/
    labs/
    case_studies/

            ▲

            │

Learning Navigation

    learning_paths/
    domains/
    roles/
    industries/
    capabilities/
    schools/
    math/
```

Educational resources are created once and referenced by multiple learning journeys.

---

# FAEP Perspective

Learning paths provide flexible navigation across the FAEP Academy.

Instead of organizing educational resources into isolated curricula, FAEP enables a single notebook, laboratory, or case study to participate in multiple learning journeys. This graph-based navigation model supports personalized learning while maintaining a single authoritative version of each educational asset.
