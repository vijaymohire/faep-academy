# FAEP Academy Notebooks

> Interactive engineering notebooks that combine theory, mathematics, architecture, implementation, simulation, experimentation, validation, and engineering reflection.

---

# Overview

The **notebooks** directory contains the primary interactive learning resources of the FAEP Academy.

Each notebook is a self-contained engineering knowledge asset designed to help learners understand concepts, implement solutions, perform experiments, validate results, and document engineering observations.

Rather than serving as code examples alone, notebooks integrate engineering thinking with practical implementation to support reproducible learning.

---

# Notebook Organization

Notebooks are organized by learner experience rather than by technology or domain.

```
notebooks/

├── beginner/
├── intermediate/
└── advanced/
```

This organization encourages gradual progression while allowing the same notebook to be reused across multiple learning journeys.

# Contributing

When creating a new notebook:

1. Start with `templates/NOTEBOOK_TEMPLATE.ipynb`
2. Follow the FAEP Notebook Standard
3. Validate notebook execution
4. Include engineering interpretation
5. Document assumptions
6. Link the notebook from the appropriate navigation resources

# FAEP Perspective

Within the FAEP ecosystem, notebooks are reusable engineering knowledge assets.

A single notebook may support multiple learning paths, domains, professional roles, industries, and engineering capabilities. By separating educational content from navigation, the Academy enables flexible curriculum design while maintaining a single authoritative version of each notebook.
