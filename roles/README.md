# FAEP Academy Roles

> Role-based navigation that organizes educational resources according to professional responsibilities, career goals, and learning objectives.

---

# Overview

The **roles** directory provides a learner-centric view of the FAEP Academy.

Rather than organizing educational resources by technology or engineering discipline, role-based navigation recommends learning journeys based on who the learner is and the skills they wish to develop.

Each role references existing notebooks, tutorials, laboratories, case studies, projects, and learning paths without duplicating educational content.

---

# Purpose

Role navigation helps answer questions such as:

- I am a student. Where should I begin?
- I am a software developer. What should I study?
- I am a systems engineer. Which notebooks are relevant?
- I am an enterprise architect. Which learning path should I follow?
- I am a researcher. Where can I find advanced engineering content?

# Creating a Role

Each role should include:

- Role overview
- Target audience
- Recommended prerequisites
- Recommended learning path
- Related notebook categories
- Related tutorials
- Related laboratories
- Related projects
- Related case studies
- Related domains
- Related industries
- Related capabilities
- Related mathematics

Roles should reference existing educational assets rather than duplicate them.

---

# FAEP Perspective

Professional roles provide a learner-focused navigation layer across the FAEP Academy.

A developer, researcher, systems engineer, or enterprise architect may all study the same notebook from different perspectives. Role-based navigation enables personalized learning journeys while maintaining a single, reusable source for each educational asset.
